# Raw Evidence

This directory stores immutable copies of requirements, DUT system details,
device output, test plans, and external specifications. Do not edit raw
evidence directly. Write analysis, summaries, and decisions in the maintained
`docs/` wiki and link back to the original source.

Recommended file name: `YYYY-MM-DD-source-topic.ext`. After adding evidence,
follow the [wiki maintenance schema](../wiki-schema.md) to update the topic,
index, and change log.
